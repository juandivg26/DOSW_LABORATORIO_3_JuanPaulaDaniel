# Parte 7 — Planning Poker

## Reflexión sobre la estimación

### 1. ¿Cuál fue la mayor dificultad a la hora de estimar?

La mayor dificultad fue determinar la complejidad real de la historia de usuario HU-01, ya que aunque inicialmente parecía una funcionalidad sencilla, al analizarla se identificaron varias acciones involucradas, como agregar productos, modificar cantidades, eliminar productos y validar que los productos estén disponibles. Por esta razón, fue necesario considerar la cantidad de funcionalidades que debían trabajar en conjunto y no solamente la acción principal de armar el pedido.

### 2. ¿Fue fácil llegar a un consenso?

No fue completamente inmediato llegar a un consenso, debido a que cada integrante podía interpretar de manera diferente la complejidad de la historia. Sin embargo, al comparar las estimaciones y explicar las razones de cada valor, fue posible llegar a una estimación común para la HU-01.

### 3. ¿Cómo resolvieron las discrepancias grandes?

Las discrepancias grandes se resolvieron haciendo que los integrantes que habían dado las estimaciones más altas y más bajas explicaran las razones de su elección. En el caso de la HU-01, se revisaron los criterios de aceptación y las tareas involucradas para determinar si la diferencia estaba relacionada con la cantidad de funcionalidades, las validaciones necesarias o la complejidad de implementar los cambios en el pedido. Después de discutir estos puntos, se llegó a un valor de estimación consensuado por el equipo.
