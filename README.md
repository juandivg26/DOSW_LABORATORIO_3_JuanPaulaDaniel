## ¿Qué es un pull request en GitHub? 
####Un pull request es una solicitud para integrar cambios hechos en una rama hacia otra (generalmente la principal). Permite que otros revisen el código, comenten y aprueben antes de fusionarlo.
## ¿Cómo se crea un pull request en GitHub? 
###Se crea al subir cambios en una rama y luego usar la opción “Compare & pull request” en GitHub. Allí se selecciona la rama base, se describe la modificación y se envía la solicitud.
## ¿Cómo se aprueba un pull request en GitHub? 
###Un revisor entra al pull request, analiza los cambios en la pestaña Files changed, y si está de acuerdo, selecciona Review changes → Approve → Submit review. Después, el pull request puede fusionarse con la rama principal.
